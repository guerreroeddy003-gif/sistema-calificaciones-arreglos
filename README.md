
# Sistema de Calificaciones de Estudiantes

## Descripción
Este proyecto es un programa sencillo desarrollado en Python para guardar y procesar las calificaciones de cinco estudiantes.

## Objetivo
Practicar el uso de arreglos o vectores, índices, ciclos, condiciones y operaciones matemáticas.

## Lenguaje utilizado
Python 3.

## Funcionalidades
- Mostrar las calificaciones iniciales.
- Consultar una nota mediante su índice.
- Recorrer las calificaciones con un ciclo for.
- Calcular el promedio.
- Identificar la nota más alta y la más baja.
- Contar estudiantes aprobados y reprobados.
- Modificar una calificación.
- Mostrar el vector actualizado.

## Cómo ejecutar el programa
1. Instalar Python 3.
2. Descargar el archivo sistema_calificaciones.py.
3. Abrir una terminal en la carpeta donde se guardó.
4. Ejecutar el comando:

   python sistema_calificaciones.py

5. Escribir una nueva calificación entre 0 y 100 cuando el programa lo solicite.
